## Purchase APIs 

- POST   /api/v1/purchases
    Create purchase

- GET    /api/v1/purchases
    Get own purchase history

- GET    /api/v1/purchases/{id}
    Get purchase details

- POST   /api/v1/purchases/{id}/confirm
    Confirm/process purchase payment

- /api/v1/purchases/qr/{urlid} 
    Purchase QR CODE
